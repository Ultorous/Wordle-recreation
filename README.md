# Wordle-recreation

##Problem:

For my CS-143 project, I would like to recreate the game wordle, but using words which are not just limited to five letter in length. For now, the length of words is limited to two letters and will be all the legal scrabble two letter words. I'd like for each word to be stored in a dictionary. When the game starts the game will create a new "word" object and read in one of the two letter words from the dictionary into the word object stored in an array. The program will ask for user input, at which point the user will provide a two letter guess. The word object will contain methods which perform all the actions Wordle performs when checking the user input against the word which is being guessed. the program will then provide output consistent with the game Wordle telling the user which letters are contained within the word object and which letters are in the right place.

##Reflection:

Gen AI is extemely competent and powerful. During this process I was able to explain what I wanted to create, and it interpreted my vision correctly, asked for clarifying input on ambiguous portions of the project, and gave me information I had not considered or heard about. here are the pros of the process: From just a few prompts Claud was able to generate several documents and internally test the code it generated. This meant that what it delivered to me was very close to what I wanted the finished project to be. Most of the effort on my part was thinking about what I wanted the project to be and how I wanted it to meet project specifications. The actual "grunt" work of coding was taken care of by Claude quickly and effectively. The cons of the process were this: In general I do not want to give Claude free reign over this project, or any project I do. The less ambiguity in what I want the outcomes to be, the better. This means that I had to think a lot about what I wanted Claude to make and the project was not as simple as saying GO. Another con is that Claude took several minutes worth of thinking to respond to each prompt I wrote. This is not bad in terms of the amount of time Claude took (several minutes is much quicker than an hour worth of me programing myself), but in terms of me getting distracted and losing focus for those several minutes. I think this process could very well be more difficult for someone with ADHD. I also have found an additional problem with using Claude on technically demanding projects is that I am one of the weaker links in the process. Claude can't truly "comprehend" any of the material we are chatting about, and I need to take time to absorb and understand the material. True comprehension only comes with dedicated time and effort, and a purposeful effort to ignore the conclusions Claude come to from an initial review of material.
