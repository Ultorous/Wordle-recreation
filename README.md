# Wordle-recreation

##Problem:

For my CS-143 project, I would like to recreate the game wordle, but using words which are not just limited to five letter in length. For now, the length of words is limited to two letters and will be all the legal scrabble two letter words. I'd like for each word to be stored in a dictionary. When the game starts the game will create a new "word" object and read in one of the two letter words from the dictionary into the word object stored in an internal array. The program when run from a driver class will ask for user input. The user will provide a two letter guess. The word object will contain methods which perform all the actions the game Wordle needs to perform when functioning correctly. The program will then provide output consistent with the game Wordle, telling the user which guessed letters are contained within the word object and which guessed letters are in the right position.

##Reflection:

Gen AI is extremely competent and useful. Here are the pros of the process: During this project I was able to explain what I wanted to create. Claude interpreted my vision correctly, asked for clarifying input on ambiguous portions of the project, and gave me information I had not considered. From just a few exchanges Claud was able to generate several documents and internally test the code it generated. What it delivered to me was very close to what I wanted the finished project to be and worked well. Most of the effort on my part was thinking about what I wanted the project to be and how I wanted it to meet project specifications. The actual "grunt" work of coding was taken care of by Claude quickly and effectively. The cons of the process were: In general I do not want to give Claude free reign over this project, or any project I do. The less ambiguity in what I want the outcomes to be, the better. This means that I had to think a lot about what I wanted Claude to make for me and the project required more effort than simple as saying GO. Claude took several minutes worth of thinking to respond to each prompt I wrote. This is not bad in terms Claude took several minutes (several minutes is much quicker than an hour worth of me programing myself), but in terms of presenting distraction opportunities to me. I think this process could very well be more difficult for someone with ADHD. Lastly, regardless of what Claude outputs, I'm still the one being graded. Even though using Gen AI takes a lot of the burden off of me, I'm still ultimately responsible for understanding what it has written and making sure that it successfully meets all requirements. 

This next comment is not directly related to this particular project, but a personal project I have used AI assistance with. I have found an additional problem with using Claude on technically demanding projects is comprehension. Claude can't truly "comprehend" any of the material we are chatting about, and I need to take time to absorb and understand the material. True comprehension only comes with dedicated time and effort, and a purposeful intention to ignore the conclusions Claude come to from an initial search of the web. This means that if a project I'm working on involves research along with coding, Claude has a much smaller effect on the research portion of the project than the coding portion.
